🚀 How to Run Angular Practicals

Step 1: Install Node.js

Make sure Node.js and npm are installed.

Check the versions:

node --version
npm --version

Step 2: Install Angular CLI

npm install -g @angular/cli

Step 3: Create an Angular Project

ng new angular-practical

Step 4: Enter the Project Directory

cd angular-practical

Step 5: Start the Development Server

ng serve

Open the following address in your browser:

"http://localhost:4200/"

⚛️ How to Run React Practicals

Step 1: Create a React Project Using Vite

npm create vite@latest react-practical -- --template react

Step 2: Enter the Project Directory

cd react-practical

Step 3: Install Dependencies

npm install

Step 4: Start the Development Server

npm run dev

Open the URL displayed in the terminal, usually:

"http://localhost:5173/"
